# AFR/INDEX — The All-Time Afrobeats Index 2026

Full 50 All-Time ranking (9-metric formula, **no streams**) + Full 50 Current ranking (momentum + platform heat, streams count).

## Features
- Separate metrics for All-Time vs Current
- Real artist photos
- Detailed bios, achievements, show fees, earnings, fun facts
- Net Worth Index (20 artists)
- Editorial Discussion
- Method page explaining both formulas

## Live preview
Enable **GitHub Pages** (Settings → Pages → Deploy from main branch → / root) then visit:
`https://codewithgojo.github.io/afrobeats-index/`

## Local
Open `index.html` with the `artists/` folder next to it for images.
